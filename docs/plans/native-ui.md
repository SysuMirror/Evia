# 控制台自建组件迁移

状态：共享原生基础、现有登录/项目页面迁移及 Ant Design 依赖清理已完成，交互状态专项修复已验证，证据见 [前端验证记录](../verification/native-ui-2026-11-07.md)。下面的阶段 1–4 已执行，阶段 5 的业务页面继续按已验证服务端能力交付。本计划适用于维护 Evia 的开发人员和 coding agent。

已交付 Button、Input、Textarea、Select、Checkbox、Field、Alert、Badge、原生 Modal、DataTable、分页、通知、复制和共享布局。Tabs、日期/条件编辑器与专业图表将随真实业务页面补齐；不能把基础组件交付理解为全部分析界面已完成。

## 组件与依赖边界

`packages/design-system` 负责 Evia 自有 React 组件、原生 HTML 语义、样式变量和共用交互。`apps/console` 负责业务状态、权限、表单数据与生成客户端调用；React Router 和 React Query 继续承担路由与服务端状态管理。

| 层次 | 交付内容 |
| --- | --- |
| 样式和布局 | 颜色、字体、间距、圆角、焦点、密度，Brand、DesignProvider、WorkspaceShell、AuthLayout、PageHeading、DataSurface |
| 基础操作 | Button、Input、Textarea、Select、Checkbox、Field、Badge、Alert、CopyButton |
| 复合交互 | 原生 dialog、Tabs、语义化 DataTable、PaginationBar、通知和异步状态面板 |
| 专业渲染 | 图表按实际需求选择成熟库，由 Evia 组件封装并按需加载 |

普通组件使用原生属性和事件、显式 React 状态。表单使用原生提交与校验，并呈现业务字段错误。迁移后的组件移除底层 Ant Design 依赖及样式。图表等专业依赖的引入记录用途、无障碍能力、维护成本和体积影响。

## 交付顺序

1. **记录基线。** 固定工具版本和生产构建方式，记录登录页、项目页的入口及延迟加载 JavaScript/CSS 原始和 gzip 体积。记录浏览器加载与交互数据、设备和网络条件、视口与样本数，保留桌面和移动端截图。
2. **建立共享基础。** 先完成样式变量、布局、原生控件和状态面板，确定稳定的组件接口，再开发弹窗、表格和分页。保持共享包与业务查询、权限策略分离。
3. **迁移已有页面。** 依次迁移登录、工作区、项目列表、创建和详情交互，保留现有 API、会话缓存、失败重试、未保存输入保护和键盘行为。每个可运行阶段单独提交。
4. **移除旧依赖。** 全部调用方迁移后清理 Ant Design 及其样式导入，更新清单和锁文件，检查产物的运行时依赖。比较前后构建和交互数据，处理退化。
5. **交付业务页面。** 基于已验证的事件目录、发布、来源和查询 API 扩展控制台。发布保存、交付就绪、显式激活分别展示真实状态；状态以当前服务端返回为准。业务功能按同一组件及验收规范开发。

## 视觉与交互要求

遵循 [界面规范](../standards/ui.md)：浅灰画布、白色内容面板、克制的蓝色主操作、清楚的排版层级和适当的信息密度。沿用已生成的 Evia 图标，参考已有视觉样例的布局原则。页面标题直接配相关操作，帮助信息放在对应控件和恢复反馈旁。中文并列状态使用逗号，去除冗余副标题和英文眉题。

组件需要覆盖加载、空数据、错误、权限不足和成功状态。表单失败保留输入，修订冲突允许恢复；退出、路由切换和浏览器返回保护未保存内容。按钮忙碌时保留稳定的可访问名称。字段关联标签、提示和错误。弹窗使用原生语义，验证 Escape、初始焦点、嵌套确认和关闭后的焦点恢复；放弃编辑采用安全的默认焦点。

桌面和窄屏都能完成所有已有操作。表格横向滚动限制在表格容器内，弹窗内容可滚动且底部操作可达。支持可见键盘焦点和减少动画偏好。图表提供单位、时区、时间范围、精度及可访问的文字或表格表示。

## 验收与分工

共享组件和业务页面分别指定文件范围及负责人，依赖清单和锁文件由集成负责人统一修改。先约定组件接口再并行迁移，避免不同人员同时改同一文件。

每个交付阶段运行格式、类型与生产构建检查。浏览器验证连接真实后端，覆盖成功和失败操作、键盘、焦点、未保存输入、窄屏及长文本，并检查未捕获异常。保留既有登录和项目回归用例；新增测试针对实际交互风险。独立浏览器验收后提供新的桌面和移动端截图，并人工检查布局。

性能记录须可复现，采用相同条件比较入口体积、延迟加载体积和交互结果；按实际测量决定缓存、记忆化和虚拟列表。移除组件库本身不代表性能已提升。迁移结束时把实际结果和剩余项写入 [PROGRESS.md](../../PROGRESS.md)。
