# 核心控制台验证，2026-11-08

本轮交付事件定义、发布激活、接入来源和分析查询四个真实工作区。后端先补齐受权项目读取、当前环境激活读取及不可变事件版本读取，再接入共享客户端和自建组件。没有新增可保存布局的看板、浏览器 SDK 或身份图解析。

本地使用 Go **1.27.3**、Node **24.22.1**、pnpm **11.25.0**、Vite **8.3.6** 和 Chromium **158.0.8127.18**。依赖为专用 PostgreSQL **17.9**、Kafka **4.4.0**、ClickHouse **26.8.36.3**、Redis **8.10.3**。API、接收和查询工作进程运行同一冻结可执行文件，SHA-256 为 `f05f6a6d7af3de4e47bad8a9d28cb692ccfcfaa25ad9ce9c32d7ff24b953de3c`。

最终前端生产文件复制到独立预览目录后保持不变。页面入口为 `index-B_R3Axyu.js`，样式为 `index-CVss_8LO.css`。业务浏览器用例访问本机 5173 的生产预览，共享组件使用独立的 5174 测试入口。测试源码不进入生产构建。所有业务账号、事件和身份标识均为合成数据，私有运行配置保存在仓库之外。

真实链路准备器显式创建专用 Kafka 主题，并按校验和账本执行 ClickHouse 迁移；没有插入事件、就绪标记或查询结果。发布就绪来自 Kafka 探针与 ClickHouse 回读，数据从公开接收 API 进入管道。完整复验方式见 [运行说明](../runbooks/console-verification.md)。

## 业务与交互边界

| 用例组 | 验证内容 |
| --- | --- |
| 访问页面，5 项 | 真实登录失败恢复、项目创建/详情、持久化、CSRF/Origin、移动端、键盘和忙碌状态、未保存内容保护、会话失效 |
| 共享组件，6 项 | 原生控件事件、焦点/错误/悬停组合、只读/禁用、复制与通知生命周期、Tab 键盘语义、未保存路由的确认/取消及迟到完成 |
| 分析参数，3 项 | 自定义页面事件的 PV 口径、快照标签、UID/匿名 UV、零/false/空数组、属性版本和环境、有序漏斗与范围上限 |
| 来源 Origin，3 项 | 允许列表解析、规范化与非法输入，不能把路径或通配符当作合法 Origin |
| 核心业务，1 项 | UI 建项目和事件，真实 PATCH 失败后保留输入，重试保存并验证，发布指定修订，等待真实就绪并显式激活，创建浏览器来源，公开接收，查询和环境切换 |
| 服务端来源，1 项 | 密钥默认隐藏且确认后才能关闭，实际轮换已提交但响应丢失，相同幂等键和请求体重试只产生一次修订，普通读取不返回密钥，停用后公开配置拒绝 |

核心业务用例发送 **3 个事件**，查询得到计数/PV **3**、精确原始 UID UV **2**，字段筛选仍得到 **3**，指定 UID 旅程保留 **2 条**记录，有序漏斗返回 **2 个步骤**。另检查空结果、放弃修改的取消/确认及切换环境后的隔离。PV 显式选择合成的已发布页面事件，不依赖尚未实现的系统事件 SDK。

错误场景中断或延迟真实请求，没有替换成功 API 回复。密钥用例关闭自动截图、视频和请求轨迹；安全业务页面另行截图。图表截图使用浏览器减少动画偏好，避免捕获 JavaScript 动画的首帧。浏览器用例检查未捕获异常。最终保留桌面事件、来源、指标、趋势和 **390×844** 手机旅程共五张截图，人工检查无通知遮挡或密钥内容，页面没有横向溢出，表格在自身容器滚动；趋势单点 **2 UV** 可见。

评审另修复了会话/权限变化后的迟到回调、未知成功响应的幂等恢复、导航确认的重复触发，以及趋势图时间轴、时区和 tooltip 边界。浏览器操作中的运行中任务取消受执行速度影响，尚未建立确定性的端到端用例；真实后端取消测试仍是此行为的现有证据。

## 限制

本地 rootless Docker 的共享 cgroup 统计曾使 ClickHouse 把执行环境总 RSS 当作自身内存。仅在可丢弃的本地容器中关闭该统计来源，保留应用 **1.5 GiB** 内存预算，未修改仓库 Compose 配置。没有由此宣称容器 cgroup 限额或生产资源隔离成立。

本次证明功能和交互链路，不证明千万用户容量、高可用或生产部署完成。查询仍是有界、覆盖状态暂定的快照，原始 UID 不会自动合并登录前匿名数据。可保存和布局的看板、版本化指标、浏览器 SDK、身份图、公开接入 skills/CLI、成员管理、导出及数据生命周期仍在 [开发进度](../../PROGRESS.md) 中保留为开放项。
