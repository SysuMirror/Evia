# 控制台布局与交互复验

本轮改善现有事件、发布、来源和查询工作区，不增加保存分析或自定义看板能力。普通控件继续使用 Evia 自建 React 与原生 HTML，图表保持按需加载。

## 实现

- 白色主区、浅灰侧栏与结果卡，紧凑的项目/环境上下文和带图标的导航。字段、操作、状态与结果有明确层级，页面标题不增加重复说明。
- 查询主条件保留在工作台，时间、过滤、查询设置和漏斗配置分别在原生弹窗中编辑。完成时校验当前部分，运行时校验完整请求；草稿摘要与已提交结果分别保留。
- 真实 Tab 面板包含查询表单。预设不自动创建查询，动态条件增删保留有用焦点，错误定位到对应输入，结果仍保留授权、轮询、取消和过期边界。
- 模态框恢复焦点时让位于后续交互，触发器被移除时使用连接中的上下文目标。通知队列同时保护鼠标悬停与键盘焦点，按钮具有持续的选中状态。
- 事件字段分组、来源详情底部操作和发布状态摘要共享基础组件。高级 JSON 报错自动展开；开始修正后不会折叠正在编辑的区域。
