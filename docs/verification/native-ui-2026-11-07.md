## 交互验证

页面用例通过真实 API 和合成账号验证，失败场景使用请求中断或延迟后放行真实请求，不返回模拟成功数据。共享组件用例在独立 Vite 页面和 React StrictMode 中验证浏览器控件行为，其中异步剪贴板适配器使用可控完成时机来覆盖生命周期竞态。

| 用例组 | 实际覆盖 |
| --- | --- |
| 页面，5 项 | 登录失败恢复、项目创建失败保留输入与重试、持久化详情、真实剪贴板、CSRF/Origin、移动端及嵌套 Escape/焦点、未保存内容的返回/导航/退出保护、真实会话失效及重新认证 |
| 页面交互加验 | Enter/Space 单次激活、标签点击聚焦、表单 Enter 只发送一次 POST、请求中不能重复提交或关闭、刷新完成恢复原焦点且不抢新焦点、成功通知关闭后回到创建触发器、字段错误关联及提示 |
| 组件，4 项 | Select/Textarea/Checkbox 的原生标签/键盘/变更，readonly 可选择但不可改，disabled 不能激活，事件转发与 preventDefault，五种按钮按下/键盘焦点样式，复制值变化或卸载后的迟到完成，通知焦点/悬停期间暂停消失与关闭恢复 |
| 组合状态加验 | readonly + disabled 以禁用状态为准，不能聚焦/编辑；错误或聚焦输入框悬停时仍保持对应边框，移动端焦点环完整可见 |

五项页面用例均有通过记录，新增及变化的交互按影响范围复验；最后页面相关两项在新版 JS 行为上通过，耗时 **9.5 秒**。四项独立组件用例整组通过，耗时 **7.0 秒**；最后 readonly/disabled 样式修正后复验受影响用例通过。不是把这些分批执行描述成一次全套运行，托管 CI 的整套结果以实际工作流记录为准。

浏览器使用 Chromium **158.0.8127.18**。检查没有未捕获页面异常。桌面 **1440×1000**、手机 **390×844** 的登录、项目、创建和详情截图均已人工检查；另检查 **320 px** 长账号名、输入错误及焦点环。页面无横向溢出，表格滚动限制在内容区域，弹窗操作可达。320 px 长账号测试只临时替换可见文本，未修改账号或业务 API 数据。

原生 dialog 的 Tab 可以经过浏览器自身界面再返回弹窗，测试确认焦点没有进入 inert 背景控件；没有为满足过严的测试假设新增 JavaScript 焦点陷阱。失败调试的会话相关轨迹已清理，认证状态不写入仓库或截图。

## 同条件浏览器采样

两端均为生产预览、同一真实 API、同一组 **8 个业务项目**，相同 Chromium 版本、1440×1000、无 CPU 限速、无网络限速的本机环回连接。每个路由分别使用 5 个全新浏览器上下文，项目页复用私有已认证状态；每组复用浏览器进程。旧表格额外生成一个隐藏测量行，已与真实业务行分别计数，未将其当作第九个项目。

就绪时长从导航开始到相应页面/项目内容可见并经过两帧，包含 Playwright 的等待成本；弹窗时长也使用可见后两帧。这些不是 INP 或动画完全结束时间。下面为 5 个样本的中位数：

| 测量，ms | 旧版 | 新版 |
| --- | ---: | ---: |
| 登录页观察到的就绪 | 225.4 | 133.2 |
| 登录页 FCP | 124 | 80 |
| 项目页观察到的数据就绪 | 955.2 | 890.2 |

该样本证明本次构建和测试环境下的变化，不能外推为公网弱网体验、所有终端或生产服务等级。后续新增图表及更多行数据时，需要重新记录同条件样本和查询成本。

## 复验入口

按 [开发说明](../runbooks/development.md) 准备真实 API 及专用账号，私下提供 `EVIA_E2E_USERNAME` / `EVIA_E2E_PASSWORD`，然后运行 `pnpm test:browser`。Playwright 启动或复用 5173 的控制台和 5174 的测试组件页面；本次本地页面验证在 5173 使用生产预览。共享组件可单独运行：

```sh
pnpm exec playwright test tests/browser/components.spec.ts
```

性能复验时先分别保存两端生产包，依次用相同端口及 API 提供服务，固定业务数据和测试条件，再按上述路由、可见目标及两帧定义采样。前端业务页面、Tabs、日期/条件编辑器和图表将在各自功能交付时继续使用同一状态与验收规范。
