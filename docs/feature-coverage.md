> 生产化硬阻塞的证据导航与剩余外部依赖清单见 [production-readiness.md](production-readiness.md)。

核对日期：2026-11-09 UTC。原始核对基线为 `0da560b`。核对后已交付浏览器 SDK、版本化看板、独立机器访问与公开业务接入 skills，真实跨域上报/查询、看板和机器工具接入链已通过。新后端已通过 Go 检查和完整真实 PostgreSQL 竞态测试，SDK 已通过 20 项单元测试；各层证据分别记录，不能相互替代。原始平台范围全部保留，不以缩小范围换取“完成”。

“已实现”仅指该行写明的现有行为；“部分”指基础存在但原始需求仍有缺口；“未实现”包括只有设计、契约或样例的能力。开发中的条目仍属于未完成工作。测试通过、页面可访问和生产容量分别判断，不计算完成百分比。
